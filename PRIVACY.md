# SignalShift privacy policy

SignalShift runs locally. It has no accounts, ads, telemetry, network client, or automatic uploads. This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

SignalShift reads audio endpoint names and identifiers to display devices and switch Windows defaults. Preferences, selected endpoints, shortcut combinations and profiles are saved in `%LOCALAPPDATA%\Sonora`. Import backups and error logs remain on the computer. SoundSwitch migration reads its local configuration without changing it.

Exporting settings writes a user-selected text file containing preferences, profiles, audio device names and identifiers, and startup preference. Export files can contain information about your hardware and setup; share them only intentionally. SignalShift does not upload them.

When requested, SignalShift changes default playback/recording endpoints and optionally communications defaults. It registers chosen global shortcuts while running. Startup is opt-in. To uninstall the portable app, turn off startup, quit from the tray, and delete the executable and local settings folder. Export preferences first if you want to retain them.

GitHub hosts this source code, downloads and build infrastructure. SignPath would process build artifacts and maintainer account data if its signing application is approved. Those services have their own privacy policies; the installed SignalShift application does not contact them.


Microsoft Store distribution was discontinued on 24 October 2026. Deleting the Store product does not itself close the developer account or erase records retained by Microsoft.

SignalShift 2.1 has no camera access or camera component. Appearance and profile-cycle shortcut preferences are stored locally with the other settings. Retired camera fields in older imports are ignored.
