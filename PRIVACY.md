# SonarShift privacy policy

SonarShift runs locally. It has no accounts, ads, telemetry, network client, or automatic uploads. This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

SonarShift reads audio endpoint names and identifiers to display devices and switch Windows defaults. Preferences, selected endpoints, shortcut combinations and profiles are saved in `%LOCALAPPDATA%\Sonora`. Import backups and error logs remain on the computer. SoundSwitch migration reads its local configuration without changing it.

Exporting settings writes a user-selected text file containing preferences, profiles, audio device names and identifiers, and startup preference. Export files can contain information about your hardware and setup; share them only intentionally. SonarShift does not upload them.

When requested, SonarShift changes default playback/recording endpoints and optionally communications defaults. It registers chosen global shortcuts while running. Startup is opt-in. To uninstall the portable app, turn off startup, quit from the tray, and delete the executable and local settings folder. Export preferences first if you want to retain them.

GitHub hosts this source code, downloads and build infrastructure. SignPath would process build artifacts and maintainer account data if its signing application is approved. Those services have their own privacy policies; the installed SonarShift application does not contact them.
