# SignalShift 2.5.1 — Six more worlds of color

Settings → Appearance now offers **14 themes**. New looks are **Mystic, Solar, Futuristic, Winter, Noir and Scary**, alongside the existing eight. Every theme has a clickable preview, saves your choice and follows the same shared, bounded palette cache. Winter is a light preset; the other new presets are dark.

Settings also adds **Microphone icon** controls: show or hide the separate status icon, or open Windows' taskbar visibility settings. To keep it beside the clock, drag it out of the **^** hidden-icons menu. Windows remembers that preference; its documented interface reserves promotion from the hidden area to the user. This is a setup shortcut, not an automatic force-pin switch.

The GitHub page now includes a clearer download/setup flow, current sample screenshots, a complete theme guide, microphone/tray setup, privacy information and links to existing trust/performance documentation.

Validation covers all theme selections, settings roundtrips, contrast and palette completeness, preview rendering, microphone-icon visibility and shared-resource ownership, plus the existing audio, shortcut, updater and repeated-switch safeguards. No browser components, fonts, dependencies, background animations or polling were added.
