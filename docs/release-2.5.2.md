# SignalShift 2.5.2

Settings now includes **Reset settings to defaults**. Confirming restores the original theme, shortcuts and preferences, clears profiles, and disables Start with Windows. The confirmation lists the changes, including enabling automatic updates and disabling the microphone-live startup option.

A restorable text backup is saved before any change. Its location appears in Settings after the reset; choose **Import settings file** to restore it. The current output, input and microphone mute state are unchanged. The current default devices become the initial shortcut cycle choices.

Reset diagnostics cover defaults, current-device selection, backup restoration and locked-file failure. Existing audio, appearance and updater checks remain in place.

This portable release is unsigned. See the repository's Windows trust guidance before running it.
