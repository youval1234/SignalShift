# SignalShift 2.4.1 — Active profiles

The profile matching your current output/microphone setup is highlighted with the same green-tinted surface used for active audio devices. An ACTIVE badge and Active button label make the current setup easy to identify.

The highlight follows device-default notifications and refreshes after profile activation. Switching devices outside the app clears or moves the highlight to the matching setup. Profiles that leave one side unchanged match only their configured side; an empty profile is never marked active. Without an explicit recent selection, a complete matching pair takes priority over a partial setup.

The Settings footer also follows the update-check result so it no longer remains on the checking message after completion.

No new background polling is added. Existing themes, shortcuts, microphone controls and update preferences remain supported.
