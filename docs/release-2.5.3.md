# SignalShift 2.5.3

Refines wording throughout Devices, Shortcuts, Profiles, Settings, audio tests, tray tooltips, and update messages. The reset button now reads **Reset to default settings**, with clearer explanations of what changes and how to restore a backup.

Shortcut buttons now say **Change shortcut**. Profile cycling, microphone startup behavior, mixed microphone states, and automatic updates have clearer descriptions. Functionality and settings are unchanged.

This portable release is unsigned. See the repository’s Windows trust guidance before running it.
